# knowledge

Local store of researched reference facts (git-ignored; only this README is tracked): platform export formats, instrument identity, tax and product rules. One `.md` per research, indexed in `../KNOWLEDGE.md`. Rules: `RULES.md` section B. Look up: `scripts/knowledge-find.py`; add: `scripts/knowledge-add.py`. Daily news is not stored here: it becomes a signal (`scripts/signals.py`).
