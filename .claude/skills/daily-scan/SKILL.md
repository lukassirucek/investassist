---
name: daily-scan
description: Daily orchestrator - reads bank/broker mail, rebuilds the exposure map and watchlist, searches news, logs signals, runs the top-15 holding outlook, writes the digest and the dashboard, republishes the dashboard artifact and routes alerts. Use for the scheduled daily run or on "run daily scan".
---
Pipeline (all paths relative to the project root; run scripts with `python3 -I`):
1. **Refresh data**: `scripts/build_master_index.py data/index data/fx/fx_latest.csv` -> `scripts/build_exposure_map.py` -> `scripts/build_watchlist.py`. If any index in `data/index/` is older than 35 days, the dashboard flags it as stale. FX: if `data/fx/fx_latest.csv` is older than 7 days, look up each non-base currency against the base currency via WebSearch/WebFetch (cite the source) and write them with `scripts/fx_set.py --date <date> CCY=rate ...`.
1b. **Mail**: run `ingest-email` for ALL routes in `config/sources.yaml` (skip if no mail connector). Every relevant mail is logged with `scripts/mail_events.py`; `review`/`urgent` events show in the dashboard and go to `alert-triage`. Newsletters are leads only (verify with WebFetch).
2. **Search**: read `data/exposure/watchlist_queries.csv`. Run T1 queries every day (batch in parallel, WebSearch mode standard); T2 daily, up to 4 names per query; T3 on Mondays only. Also run the manual items in `config/watchlist.yaml` (macro, housing, climate). Add date words to queries.
3. **Verify before logging**: search results are headlines only. For every candidate signal open the article with WebFetch, confirm the publication date (discard anything older than 14 days unless it is a still-upcoming dated catalyst) and the concrete fact. Never log from a title alone.
4. **Log signals**: JSON list to `data/signals/raw/<date>_scan.json` (field spec in `scripts/signals.py`; prefixed tags; basis FACT / INFERENCE / HISTORICAL PATTERN; impact range is an explicit assumption). `python3 -I scripts/signals.py ingest <file>`. Close resolved signals (status=done), re-check dated catalysts.
5. **Top-15 outlook**: follow `holding-outlook` (news + company news + press releases per holding, sourced drivers, `outlook.py ingest`, `missing` must be none, record outcomes for calls whose horizon ended). Re-use what steps 1b-4 already found.
6. **Digest + dashboard**: `python3 -I scripts/signals.py digest <date>` then `python3 -I scripts/build_dashboard_html.py <date>`. Publish `data/reports/<date>/dashboard.artifact.html` with the Artifact tool to the URL in `config/artifacts.yaml` (first time: publish, then store the URL there) (same file path or `url` = that URL, so the link never changes). If no artifact tool is available, leave the HTML file (`dashboard.html`) in `data/reports/<date>/` and give its path; never create a second artifact for the same dashboard.
7. **Route**: `alert-triage` for ALERT items and `urgent` mail. Reply with <= 10 lines: alerts, urgent mail, outlook leans that are not neutral, the next dated catalysts within 7 days, stale-data warnings, the dashboard link or path.
Rules: no trade orders - action candidates are options for review; show base-currency exposure and % of own portfolio; other owners' accounts are excluded from own totals; never invent numbers; cite URL + date for every claim; leans are tilts, not forecasts.
